# Libraries

Footprints, symbols and 3D model references for the JLCPCB/LCSC parts on the board, vendored so the project opens without any external library.

- **jlc.pretty** - Footprints, one per package
- **symbols** - Schematic symbols
- **jlc_footprints.json** - Pad counts and centres from JLCPCB, used for the pick-and-place rotations
