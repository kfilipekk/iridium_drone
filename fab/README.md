# Fabrication outputs — NAVCORE-SoOP

Generated by `tools/gen_bom.py` and `kicad-cli`. Regenerate with:

```bash
kicad-cli pcb export gerbers --output fab/gerbers/ \
  --layers "F.Cu,In1.Cu,In2.Cu,In3.Cu,In4.Cu,B.Cu,F.Paste,B.Paste,F.SilkS,B.SilkS,F.Mask,B.Mask,Edge.Cuts" \
  --no-protel-ext NAVCORE-SoOP.kicad_pcb
kicad-cli pcb export drill --output fab/gerbers/ --format excellon \
  --drill-origin absolute --excellon-units mm --generate-map --map-format gerberx2 \
  NAVCORE-SoOP.kicad_pcb
python3 tools/gen_bom.py
```

## One correction worth knowing about

The 5 V buck's feedback divider was originally `10k2 / 3k24`, which is
`0.8 × (1 + 10.2/3.24) = 3.32 V` — a 3.3 V rail where 5 V was intended. It was caught while
sourcing the parts: the odd E96 values were hard to buy, which prompted a recheck of the
arithmetic. Both dividers now use stocked E24 pairs: **5 V = 27k/5k1 → 5.04 V**,
**9 V = 47k/4k7 → 8.80 V**.
